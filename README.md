# 🐾 Animal Claw Master

<img src="/Assets/_Project/Gif/AnimalClawMaster.gif" width="380"/>

一款使用 Unity 製作的休閒風夾娃娃機遊戲 Prototype。  
玩家操作夾子抓取轉蛋，打開後獲得不同的動物模型，並逐步收集圖鑑內容。

---

## 🎮 遊戲玩法

- 操作夾娃娃機夾取轉蛋
- 成功抓取後會開啟轉蛋並顯示獲得的動物模型
- 具備簡單的物理互動與抓取系統
- 預計加入收藏圖鑑與更多收集內容

---

## 📱 支援平台

遊戲目前以 **Android 手機平台** 為開發目標。

---

## 📂 專案結構簡介

- `Assets/`：主要遊戲資源與素材
- `Scripts/`：夾取邏輯、轉蛋系統與 UI 控制
- `Scenes/`：遊戲主場景
- `Models/`：動物模型
- `README.md`：本專案說明文件

---

## 💡 技術亮點

- Unity 物理系統與抓取互動
- C# 遊戲邏輯開發
- 轉蛋獎勵展示系統
- 手機休閒遊戲 Prototype 設計
- AI 協助部分美術與開發流程
