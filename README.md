一款使用 Unity 製作的休閒風夾娃娃機遊戲 Prototype。  
玩家操作夾子抓取轉蛋，打開後獲得不同的動物模型，並逐步收集圖鑑內容。

---

## 🎮 遊戲玩法

- 操作夾娃娃機夾取轉蛋與金幣。
- 成功抓取後會開啟轉蛋並顯示獲得的動物模型。
- 具備簡單的物理互動與抓取系統。
- 支援遊戲狀態存檔（重新開啟後物件與金幣位置隨機產生，但記錄不遺失）。

---

## 📱 支援平台

遊戲目前以 **Android 手機平台** 為開發目標。

---

## 📂 專案結構簡介

- `Assets/`：主要遊戲資源與素材
- `Scripts/`：夾取邏輯、轉蛋系統與 UI 控制
- `Scenes/`：遊戲主場景
- `Models/`：動物模型
- `README.md`：本專案說明文件

---

## 💡 技術亮點

- **廣告 SDK 整合**：串接 Google Mobile Ads (AdMob)，實現機制完整的廣告獎勵系統。
- **數據持久化（Save/Load）**：實作遊戲狀態與紀錄保存，確保玩家進度與狀態正確儲存。
- **物理系統應用**：Unity 物理系統與夾爪抓取機制的互動與調校。
- **物件動態生成**：重新開啟遊戲後的物件隨機配置與生成邏輯。
- **AI 輔助開發**：運用 AI 協助部分美術素材產出與開發流程優化。
